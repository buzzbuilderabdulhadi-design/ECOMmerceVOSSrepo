# ZOYA GOODS - ADMIN PANEL SPECIFICATION

Version: 1.0

---

# PURPOSE

The Admin Panel is the central control system for the ZOYA GOODS eCommerce platform.

It should provide complete control over the website while remaining simple, modern, responsive, and easy to use.

Only Administrators may access the Admin Panel.

The public must never access any admin pages.

The design should be inspired by Shopify, WordPress, and modern SaaS dashboards.

---

# OBJECTIVE

Allow administrators to:

• Manage Products

• Manage Categories

• Manage Orders

• Manage Customers

• Manage Homepage

• Manage Website Content

• Manage Inventory

• Manage Coupons

• Manage Shipping

• Manage Payments

• Manage Reviews

• Manage SEO

• View Analytics

• Configure Website Settings

Everything should be editable without touching the code.

---

# LOGIN

Admin login must be completely separate from customer authentication.

Only users with the Administrator role can access the Admin Panel.

Protect all admin routes.

Automatically redirect unauthorized users.
