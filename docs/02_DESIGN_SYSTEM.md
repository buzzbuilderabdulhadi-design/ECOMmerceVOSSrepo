Version: 1.0

# PURPOSE

This document defines the complete visual identity of VOSS.

Every page, component, animation, and interaction must follow this design system.

Never randomly change colors, spacing, fonts, border radius, shadows, or component styles.

Consistency is mandatory.

Never distort it.

# TYPOGRAPHY

Style:

Luxury Fashion

Modern

Elegant

Readable

Hierarchy must always be clear.

Headings should feel powerful.

Body text should be comfortable to read.

Never use playful fonts.

---

# SPACING

Spacing must be consistent.

Large breathing room.

No cramped layouts.

Use generous whitespace.

Premium brands use space to create luxury.

Follow an 8px spacing system.

---

# BORDER RADIUS

Small

Medium

Large

Extra Large

Cards should have subtle rounded corners.

Buttons should be slightly rounded.

Avoid excessive rounding.

---

# SHADOWS

Use soft shadows.

No harsh shadows.

No outdated effects.

Cards should gently elevate.

Hover should slightly increase elevation.

---

# BUTTONS

Buttons should feel premium.

Buttons should never feel flat.
