# ZOYA GOODS - SHOPPING CART SPECIFICATION

Version: 1.0

---

# PURPOSE

The Shopping Cart is one of the highest priority features of the ZOYA GOODS eCommerce platform.

It should not simply display products.

It should encourage customers to complete their purchase by providing a premium shopping experience.

The Cart must feel fast, intelligent, elegant, and trustworthy.

The user should never feel confused.

Every calculation should update instantly.

---

# OBJECTIVE

Allow customers to:

• Review products

• Edit quantities

• Remove products

• Save products for later

• Move products to Wishlist

• Apply coupons

• View shipping costs

• View taxes

• View discounts

• Estimate delivery

• Continue shopping

• Proceed to checkout

Everything should happen instantly without refreshing the page.
